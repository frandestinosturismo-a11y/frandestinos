Editor de destinos

Personalize, crie e exclua destinos do site. Ao terminar, clique em Salvar alterações.

Conferir site ↗
  1. Escolha um destino na lista à esquerda ou clique em Novo destino.
  2. Preencha os campos. Os que têm * são obrigatórios.
  3. Para usar uma foto nova, coloque o arquivo na pasta public/images e escreva o nome do arquivo (sem .jpg) no campo correspondente.
  4. Um destino novo entra na primeira posição da lista. Use as setas ↑ e ↓ para mudar a ordem dos demais.
  5. Preencha o roteiro do dia com as etapas da saída. Horário em branco aparece como “Horário a confirmar”.
  6. Clique em Salvar alterações. O arquivo public/destinos.json é gravado direto, com uma cópia da versão anterior em public/destinos-copia-…json.
  7. Rode npm run atualizar no terminal do projeto e envie a pasta dist para a hospedagem.

Para gravar direto, o editor precisa ter sido aberto pelo servidor local do projeto (npm run editor). Sem ele, o navegador baixa o arquivo destinos.json e você substitui o de public/ pelo download.

Desfazer uma alteração: copie uma das cópias destinos-copia-…json de public/ sobre destinos.json.
